# Limitations

The catalogue covers 21 selected programmes rather than every master's programme in Singapore. Recommendations are therefore conditional on the catalogue.

Admission criteria are rarely reducible to deterministic rules. Background matching is a soft signal, and the tool does not estimate acceptance probability.

Some official pages do not publish a stable total tuition figure or use cohort-specific fees. Those values remain blank and generate a warning.

The local TF-IDF retriever is transparent and reproducible, but it captures word overlap better than deep semantic relationships. The optional foundation-model layer improves explanation quality but adds cost, latency, privacy exposure and a new failure mode.

The project author also created the evaluation labels. The completed documented second labeling pass reduced direct leakage but cannot remove confirmation bias, so the scores are reported as self-evaluation rather than independent evidence.
